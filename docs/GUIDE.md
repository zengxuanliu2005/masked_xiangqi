# 覆子使用指南

[← 返回产品介绍](../README.md) · [实现与版本记录](../CHANGELOG.md) · [安全说明](../SECURITY.md)

覆子在电脑上启动，通过浏览器游玩。可以同屏双人，也可以让同一网络的另一台设备加入；人机对战需要本机 Ollama。

## 安装与启动

准备 Node.js **22.12.0 或更高版本**、npm 和 Git。下面使用 HTTPS 克隆，无需先配置 SSH 密钥。

```bash
git clone https://github.com/zengxuanliu2005/masked_xiangqi.git
cd masked_xiangqi
npm ci
npm run build
npm start
```

打开 <http://127.0.0.1:3001>。以上启动方式适用于 macOS、Linux 和 Windows。默认仅本机可访问，双人对战无需安装 Ollama。

修改项目时，也可以使用开发模式：

```bash
npm run dev
```

网页地址仍是 <http://127.0.0.1:3001>。其他开发命令和验证范围见 [Changelog 的既有实现说明](../CHANGELOG.md#既有实现说明由-readme-迁入)。

## 第一局怎么玩

1. 首页点“新手教学”，体验选中、移动、揭面三个步骤；也可直接开始游戏。
2. 选择同屏双人、人机或局域网对战，再设置胜负规则、自动和棋与悔棋。
3. 保持“自动生成”即可得到随机布子。开局随机分配红黑，红方先走。
4. 点击当前方棋子查看合法落点，再点落点行棋。
5. 终局后可查看最终棋盘，或选择“同 Seed 再来”，用同一套初始布子重新开始。

### 盲棋规则

- 使用标准 9×10 象棋棋盘。帅、将明置，其余 30 枚棋子的真实身份打乱并盖住。
- 暗子首次按原位置对应棋种行走；走完揭面，之后按真实棋种和颜色行动。揭面后可能成为对方的棋子。
- 被吃的暗子也会揭晓身份，显示在吃子区。
- **标准模式**保留将军、应将、禁止送将与将帅照面约束，支持将死、困毙和直接吃主帅。
- **吃主帅模式**取消将军约束，以实际吃掉帅或将结束。
- 开启自动和棋后，同一局面第三次出现会判和。
- 同屏对战悔棋撤回最近一步；人机对战撤回玩家与模型的上一轮；局域网悔棋需对方同意。

### 离开、恢复与重新开始

活动局的 Seed 保密，终局后公开。也可以在开局前指定 Seed 复现布子；此时指定者已经知道该值。

刷新后可从首页“恢复上局”。**棋局只在服务运行期间保留，重启服务后无法恢复。** 人机局中自己的执方始终显示在下方；离开活动局需要确认，并会停止该局的本地控制器。

局域网对局离开或换局时会先结束原房间；遇到失败，保留原页面并按提示重试。

## 和本地模型下棋

先安装 [Ollama](https://ollama.com/)，准备一个可生成文本的模型，例如：

```bash
ollama pull qwen3:8b
ollama serve
```

如果提示 `address already in use`，通常是 Ollama 已在后台运行。用 `ollama list` 或访问 <http://127.0.0.1:11434/api/tags> 验证，不必重复启动。

1. 在“人机对战”卡片选择本机模型；embedding-only 模型不能用于对弈。
2. 选择人机对战，设置简单、中等或困难，确认开局。
3. 本机会打开独立终端控制台。模型落子后，轮到你时点击棋子操作。
4. 控制台可以查看模型实际返回的文字、最终着法、理由与耗时；模型没有返回 thinking 时不会补造。

难度默认中等。实际棋力和等待时间与模型、量化及电脑硬件有关。修改策略文本等进阶内容见 [实现记录](../CHANGELOG.md#ollama-agent-runner-与难度)。

## 和同一 Wi-Fi 下的朋友下棋

推荐先完成构建，再启用局域网：

```bash
npm run build
npm start -- --lan
```

也可以正常启动后，在电脑本机页面打开“允许同一网络的设备连接”。开发模式支持 `npm run dev -- --lan`，但会向同网段设备提供项目源码；日常联机推荐使用上面的生产启动方式。

1. 房主在电脑上选择“局域网对战 → 创建房间”。
2. 页面显示 6 位房间码和可复制的邀请链接。有多个地址时，选择与朋友设备同网段的地址。
3. 对方连接同一 Wi-Fi，打开邀请链接，确认预填的房间码加入；也可访问 `http://<房主IP>:3001`，点击“我有房间码”。
4. 双方在各自设备上操作，自己的执方显示在棋盘下方，只能在自己回合落子。

只有刚落子的一方可以请求悔棋，对方可同意或拒绝；对方继续行棋、请求超时或终局时，请求失效。对手掉线后，房主可“重新邀请”，旧房间码和旧席位随之失效。

只在可信的家庭网络使用：房间码用于入座，没有账号系统，通信使用 HTTP。请使用界面给出的 IP 链接，`xxx.local` 名称不受支持。不要在 API 前放置代理；详情见 [安全说明](../SECURITY.md)。

## 常见问题

| 情况                   | 处理方式                                                                      |
| ---------------------- | ----------------------------------------------------------------------------- |
| 3001 端口被占用        | 停止旧服务，或用 `PORT` 环境变量指定其他端口。开发模式还使用本机 24678 端口。 |
| 找不到模型             | 确认 `ollama list` 中有可生成文本的模型，回页面重新检测；开局时还会验证一次。 |
| 模型控制台没有打开     | 页面会显示可复制的手动命令，把它粘贴到本机终端运行。                          |
| Linux 没有桌面环境     | 自动打开终端需要 `DISPLAY` 或 `WAYLAND_DISPLAY`；无桌面时使用手动命令。       |
| 终端退出或控制器暂停   | 按页面提示使用“重新打开控制台”或“重启控制器”。                                |
| 朋友无法加入           | 确认局域网开关已完成切换、设备同网、邀请 IP 正确且房间码仍有效。              |
| 切换网络模式时短暂断连 | 等待页面重新确认真实状态；不要仅凭开关动作判断已经成功。                      |
| 刷新后没有恢复入口     | 浏览器存储受限可能影响恢复；服务重启也会丢失棋局。                            |
